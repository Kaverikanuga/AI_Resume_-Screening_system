About

This AI Resume Screening System is a comprehensive SaaS platform built as a Final Year Engineering Project. It leverages modern AI/ML techniques including Natural Language Processing (NLP), Named Entity Recognition, and machine learning to analyze resumes, score ATS compatibility, match candidates to jobs, and provide career guidance.

Built with Flask, SQLAlchemy, scikit-learn, spaCy, and Chart.js, the platform delivers a production-grade user experience with a premium dark-themed UI.
